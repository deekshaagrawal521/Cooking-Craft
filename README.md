Cooking Craft 🍳
A web application that helps you discover new recipes, create shopping lists, and get personalized cooking recommendations. With integrated video tutorials and a chatbot for all your cooking-related queries, Cooking Craft is your go-to assistant in the kitchen!

Features ✨
Recipe Fetcher: Get a list of recipes based on your search query.

Video Tutorials: Step-by-step cooking instructions through integrated video tutorials.

Shopping List: Automatically create a shopping list for selected recipes.

Cooking Chatbot: Ask any cooking-related questions and get quick, helpful responses.

Tech Stack 🛠
Frontend: HTML, CSS, JavaScript

Backend: Node.js (API integration for fetching recipes)

APIs: Recipe API integration for real-time recipe fetching

Chatbot: Basic chatbot built with JavaScript

Usage 🥘
Search for Recipes: Enter ingredients or dish name in the search bar to get recipe suggestions.

View Recipe Details: Click on any recipe to view its ingredients, instructions, and tutorial videos.

Add to Shopping List: Automatically add ingredients to your shopping list with a single click.

Interact with Chatbot: Ask the cooking chatbot for help or recipe suggestions.
